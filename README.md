# Hi, I'm Aygun 👋

- **Post-quantum migration** of IoT identity, including hybrid classical/PQ signatures
- **Threshold signatures** (FROST) for decentralized attestation
- **LLM-assisted cyber threat intelligence sharing** in IoT environments
